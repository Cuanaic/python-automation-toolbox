Python 自动化工具箱

四个命令覆盖四类高频重复劳动：合并表 / 采数据 / 出报表 / 理文件。

License MIT Python 3.9+ 依赖 仅标准库 版本 v1.0.0

工具

excel_batch

merge · split · clean

Excel / CSV 批量合并、按列拆分、去空行去重去首尾空格。

data_collect

世界银行等公开数据

内置限速、失败重试、断点续传，中断了接着跑。

report_gen

CSV → 单文件 HTML

图表内嵌，零前端依赖，微信里发出去就能看。

file_organizer

按类型 / 日期归档

支持 --dry-run，先看它想怎么挪，再决定动不动。

跑一遍

git clone https://github.com/Cuanaic/python-automation-toolbox.git
cd python-automation-toolbox
python samples/make_samples.py

python tools/excel_batch.py merge samples/orders_q1.csv samples/orders_q2.csv -o all.csv
python tools/report_gen.py --input all.csv --title "订单报表" --chart-column 金额 --label-column 月份
python tools/file_organizer.py --dir ~/Downloads --dry-run
